# Changelog

All notable changes follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-13

### Added

- Seven-stage workflow for deep reading one academic paper.
- Local PDF and read-only Zotero input routing with optional OCR fallback.
- Page-level evidence records and Obsidian block backlinks.
- Obsidian note-bundle templates and safe directory initialization.
- PDF readability, title safety, note initialization, and evidence-link audit scripts.
- GB/T 7714—2025 as the default citation style, with explicit verification boundaries.
- ccswitch-compatible packaging and SHA-256 release verification.
