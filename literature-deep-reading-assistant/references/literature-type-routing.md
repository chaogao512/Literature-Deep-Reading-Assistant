# 文献类型路由

允许一篇文献具有一个主类型和至多两个次类型。先给出分类依据，再选择分析模块。

| 类型 | 优先模块 | 重点审查 |
|---|---|---|
| 概念／理论型 | 问题、概念、理论、分类、框架、边界 | 定义来源、概念边界、逻辑完备性、经验支持 |
| 框架／模型型 | 构成、层级、关系、机制、反馈 | 要素遗漏、层级混用、路径证据、可检验性 |
| 定量实证型 | 理论、假设、样本、工具、数据、结果、证据 | 操作化、信效度、统计假设、效应量、因果外推 |
| 定性研究型 | 情境、抽样、资料、编码、范畴、机制、理论生成 | 研究者位置、饱和度、反例、可信度、可转移性 |
| 混合研究型 | 问题、设计类型、定量链、定性链、整合 | 两类资料何时及如何整合、整合增量 |
| 综述型 | 检索、纳排、编码、主题、演进、争议、空白 | 检索完备性、偏倚、质量评价、综合方法 |
| 设计／开发型 | 需求、设计原则、迭代、实现、评价 | 设计依据、过程透明度、评价与设计目标一致性 |
| 政策／治理型 | 问题、主体、权责、工具、机制、制度情境 | 规范与事实混用、政策层级、执行条件、利益相关者 |
| 实践／案例型 | 情境、过程、行动、结果、机制、可迁移性 | 案例选择、替代解释、证据三角互证 |

不要机械要求所有类型回答相同问题。文献缺少某模块时记录“原文未提供”，不要补造。
